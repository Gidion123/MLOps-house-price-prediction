# Kenapa dipisah dari requirements.txt?
# Karena Dockerfile cuma meng-install requirements.txt. JupyterLab, matplotlib,
# dan pytest tidak punya urusan di dalam container yang melayani request user:

#
# Pin di sini sengaja lebih longgar (>=) daripada requirements.txt: paket ini
# tidak ikut dikirim ke server, jadi reproducibility-nya tidak sekritis itu.
#
# Pasang:  pip install -r requirements-dev.txt   (otomatis ikut yang production)
# =============================================================================
